# Segurança

Esta é uma implementação experimental, inadequada a dados reais. Não envie relatórios de vulnerabilidades contendo dados pessoais, detalhes exploráveis ou segredos por issues públicos. Utilize um canal privado de divulgação coordenada mantido pelo futuro repositório antes de publicação; nenhum endereço privado está configurado nesta versão local.

Os controles mais importantes são isolamento por espaço, papéis no backend, precisão de valores, auditoria, imutabilidade, concorrência e rejeição de operações repetidas. O Nextcloud administra autenticação e infraestrutura, mas não autoriza automaticamente ações financeiras.
